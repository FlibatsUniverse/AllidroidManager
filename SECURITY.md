# Security

Do not post vulnerabilities, credentials or exploit details in public issues. Use GitHub private vulnerability reporting if the repository Security tab provides it, or message ItzFlibat privately on the [Discord server](https://discord.com/invite/XszKXdqaZP). Reports about Allidroid or Allicord belong in the private reporting of the [Allidroid](https://github.com/FlibatsUniverse/Allidroid) and [Allicord](https://github.com/FlibatsUniverse/Allicord) repositories.

Keep credentials, keystores and signing passwords out of commits. Actions use job-specific permissions; untrusted pull requests build without write tokens. Releases are published only when a maintainer runs the release workflow, using signing material kept in repository secrets. Configure review requirements on main to control what reaches a release.
